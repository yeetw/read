# 閱讀統計分類對照

對照資料：`_data/categories.yml`，供 Jekyll 以 `site.data.categories` 讀取。

以國家圖書館《中文圖書分類法》（2007 年版）原版基本大綱、簡表及主表分段為依據，未混入後續修訂版。包含統計大類、簡表及綱目表三層，整理到個位數（三位數類號），不包含小數點後的細分類。

## 使用方式

- 書籍的 `category` 保持完整分類號字串，例如 `"861.57"`。
- 大類：取整數部分的百位，例如 `861.57 → "800" → 語言文學類`。
- 簡表類目：取整數部分的前兩碼並補 `0`，例如 `861.57 → "860" → 東方文學`、`177.2 → "170" → 心理學`。
- 綱目類目：去掉小數部分後查 `sections`，例如 `861.57 → "861" → 日本文學`、`177.2 → "177" → 應用心理學`。
- `"000"` 大類是「總類」，但 `"000"` 簡表類目是「特藏」；兩層需分開查表。
- 空值、格式錯誤或不在 000–999 範圍的值歸「未分類」，不可當成 `000`。有效格式為三位數字，可接小數點及一位以上數字；先去除前後空白。
- 官方簡表沒有獨立的 `700` 類目，故 `divisions` 不建立該鍵。若遇到 `700`–`709`，保留原碼，簡表統計回退到大類，並標示「未細分」。
- 統計時每筆閱讀紀錄使用一個主要分類，避免多個標籤重複計數。

## 三位數綱目的特殊情況

- `sections` 收錄 919 個無方法歧義的類號；`090`–`099` 的 10 個類號另存兩種方法，共 929 個不同類號。
- 經學 `090`–`099` 須查 `section_methods["090-099"].first.sections` 或 `.second.sections`。例如 `091` 第一法是「群經合刻」，第二法是「易經」。原書只有分類號時，無法判定採用哪一法；統計可先合併為簡表的 `090`「群經」，不可自行指定名稱。
- 官方以範圍列出的項目已展開為各個類號，範圍原文保留於 `section_ranges`。例如 `033`–`037` 都對應「各國漢學研究」。若同時有個別名稱，優先使用個別名稱：`283` 是「亞洲各國神話」，`284` 是「西洋各國神話」，`285`–`287` 使用範圍名稱「各國神話」。
- 綱目表未列出的號碼不補造名稱，例如 `045`、`700`。查不到三位數綱目時，可回退至簡表或大類，並標示「未細分」；這與空值的「未分類」不同。
- 同碼在不同層級的名稱可能不同。例如簡表 `880` 是「其他各國文學」，綱目表 `880` 是「俄國文學」，請按統計層級查表。

## 史地類的統計口徑

官方基本大綱將 600–700 合稱「史地類」。為方便分段統計，大類鍵依官方主表分為 `600`「史地類：中國史地」與 `700`「史地類：世界史地」；其中 `600` 簡表類目本身是「史地總論」。如需依基本大綱合併統計，可將兩個大類加總為「史地類」。這些名稱代表原分類表的編排，不代表作者國籍或作品語言。
